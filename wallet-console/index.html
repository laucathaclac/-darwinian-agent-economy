What this prototype does

  • Requests wallet connection using the browser's standard injected wallet API.
  • Checks BSC Testnet chain ID 97 and reads native balance.
  • Validates recipient and amount, estimates gas, then asks the wallet to approve.
  • Displays transaction hash and waits for a receipt.

This is a browser-side test harness, not unattended autonomous trading. Mainnet and ERC-20/token contract execution are intentionally disabled.
