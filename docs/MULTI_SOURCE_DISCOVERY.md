# DAE v0.9 — Multi-source discovery

GitHub Issues is only one source and can surface few genuine paid opportunities. This module adds six zero-cost search paths covering X, web-indexed Binance Square campaigns, writing contests, freelance tasks, and broader bounty/grant/hackathon programs.

## Run on Windows
```bat
python scripts\dae_external_source_discovery.py
```
Outputs:
- `reports\external_source_searches.md`
- `reports\external_source_searches.json`

## Cost and safety
- No X API reads, paid API calls, undocumented Binance endpoints, scraping, or account automation.
- These are search links, not a live crawler; they do not prove that any offer is active or funded.
- Verify original official terms, funding evidence, deadline, acceptance criteria, age/location eligibility, and payout method.
- A token reward pool is not cash income. Never pay an application fee, reveal seed phrases/private keys, or connect a wallet just to claim a reward.
- No task acceptance, submission, client contact, untrusted code execution, or spending.

This increases source coverage, not verified reward count. Funding remains unverified until independently checked.
