## Title
DAE Free Opportunity Hunter — Find Public Paid-Task Leads at No Software Cost

## Short description
A free, local-first opportunity hunter that scans public GitHub issue listings and helps you review potential bounties and paid tasks. Includes transparent triage, deadline/amount hints, scam-risk flags, and search links for X and Binance Square—without paid APIs or wallet access.

## Full description
Stop jumping between tabs just to find your next possible opportunity.

**DAE Free Opportunity Hunter** helps developers and open-source contributors discover public task leads, sort them for manual review, and keep the evidence in a readable report. It is designed to cost **$0 to run with the included features**: local Python scripts, public GitHub issue search, and external search links. No subscription, paid API key, or deposit is required by this version. Normal internet access and your own time are still required.

### What you get
- Read-only search of public GitHub Issues for potential bounty and paid-task leads.
- A local opportunity brief with candidate reward amounts and deadline text when detectable.
- Clear triage labels and reasons for manual review.
- Risk flags for common upfront-fee, seed-phrase, private-key, wallet-connection, and deposit-first language.
- Search links for X and Binance Square campaigns, bounties, and creator contests.
- Local JSON/CSV/Markdown report workflow, plus Windows one-click run and test scripts.
- No third-party Python runtime dependencies for the included scanner workflow.

### Built to keep the user in control
DAE does not connect to wallets, sign transactions, trade, spend money, accept tasks, contact clients, submit work, or execute third-party code. It gives you leads and a checklist; you decide what to investigate and whether to participate.

### Important limitations
- **A lead is not income.** Reward amounts are extracted from public text and are not independently verified as funded.
- The tool does not estimate a reliable probability of winning or getting paid.
- X and Binance Square are search-link discovery only in this version—not live API crawlers.
- It is a local MVP, not a hosted SaaS, and has no service-level guarantee.
- Users must check original rules, deadlines, payout terms, tax, IP/license terms, and age/location eligibility themselves.

### Price
**Free — $0 for the current local version.** No paid API or payment is required to use the included features. Any future hosted service would be a separate product decision and is not part of this listing.

### Quick start
1. Download the source from the repository.
2. Install Python 3.11+.
3. Run `TEST_DAE.bat` to validate the local environment.
4. Run `RUN_DAE.bat`.
5. Read `reports/hourly_opportunity_brief.md` and `reports/external_source_searches.md`.
