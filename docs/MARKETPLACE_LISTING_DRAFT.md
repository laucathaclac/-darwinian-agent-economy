# Marketplace Listing Draft — DAE Opportunity Intelligence

**Status: DRAFT — not published**

## Title
DAE Opportunity Intelligence — Read-only bounty and paid-task research

## One-line pitch
Find and triage public paid-task leads with transparent evidence scoring and exportable reports—without handing an agent your wallet or letting it accept work autonomously.

## Features
- Read-only discovery from public GitHub Issues search.
- Additional search-link sets for X, Binance Square campaign posts, creator contests, and broader bounty programs.
- Transparent triage labels, amount/deadline extraction, duplicate removal, and JSON/CSV/Markdown exports.
- Safety flags for common upfront-fee and wallet-secret scam language.
- Windows CMD launchers and no third-party Python runtime dependencies.

## What it does not promise
- No guaranteed earnings or winning probability.
- No independently verified funding yet.
- No task acceptance, code execution, account creation, client outreach, wallet signing, or payments.
- X and Binance Square are search-link discovery only in this version, not API crawlers.
- Not a hosted SaaS; runs locally on the user's Windows machine.

## Intended users
Developers, open-source contributors, and researchers who want a transparent shortlist of public task leads.

## Demo
Run `RUN_DAE.bat`, then open `reports/latest_brief.md`. For tests, run `TEST_DAE.bat`.

## Pricing proposal
Start with a free pilot / open-source demo. Consider a paid hosted version only after live-source reliability, funding-evidence review, privacy/security review, support, and a measurable user value proposition are demonstrated. Do not charge users for unverified reward claims.

## Support and limitations
Early MVP, best-effort tool, no SLA. Always verify original terms and eligibility independently.
